Procedural Level Generation in Java.

A collection of Java scripts designed to create and modify 2D game levels using two distinct procedural generation techniques.

Two Methods of Generation

1. Noise Culling & Refinement

This method, found in LevelCreate.java, starts with a random noise image. It then intelligently processes the image to remove isolated "stray" pixels and simplify complex clusters, resulting in more organic, cave-like structures.

Key Steps:

  • Reads pixel data from an input noise image.
  • Scans and removes pixels that have no neighbors.
  • Colors connected pixel clusters uniformly.
  • Saves the result as a new PNG file.

2. Shape-Based Construction

The second method, implemented in LevelCreate2.java, acts like a generative art tool. It uses a predefined library of shapes (like L-shapes, lines, and corners) and randomly places them onto a grid until the level is populated, ensuring no shapes overlap.

Key Steps:

  • Defines a collection of 2D array shapes.
  • Randomly selects, rotates, and places shapes.
  • Performs collision detection to prevent overlaps.
  • Assigns a unique color to each shape placed.

How to Run the Scripts

You can easily run these scripts yourself to generate new levels. You'll need a Java Development Kit (JDK) installed.

  1. 1.Clone the Repository: Get the source code from GitHub.
  2. 2.Navigate to Directory: Open a terminal and `cd` into the project folder.
  3. 3.Compile & Run: Use the `javac` and `java` commands to run either script.
# To run the Noise Culling script
javac LevelCreate.java
java LevelCreate

# To run the Shape-Based script
javac LevelCreate2.java
java LevelCreate2
